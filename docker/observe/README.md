# Observability Stack (105)

This directory contains the configuration for the observability stack, deployed via Docker Compose on the `observability-lxc` container.

The observability stack provides metrics collection, visualization, and monitoring across the environment.


---


## Services

| Service | Description |
|:---|:---|
| Prometheus | Scrapes and stores metrics from container and system endpoints |
| Grafana | Visualizes metrics through customizable dashboards |
| Alertmanager | Routes alerts generated by Prometheus based on defined rules |
| cAdvisor | Exposes container-level resource usage metrics |
| Glances | Exposes system-level resource metrics in a Prometheus-friendly format |


---

## Volumes

| Volume | Purpose |
|:---|:---|
| grafana_data | Persists Grafana dashboards, data sources, and settings |


---


## Grafana Dashboards

Grafana dashboards are created through the Grafana web UI and are automatically persisted inside the `grafana_data` volume.

Important dashboards are manually exported for Git-based backup and version control.

### Exported Dashboards

| Dashboard Name | File |
|:---|:---|
| cAdvisor Metrics | configs/grafana_dashboards/cadvisor.json |
| Node Exporter (Proxmox Host) | configs/grafana_dashboards/node_exporter.json |
| Pi-hole Exporter Metrics | configs/grafana_dashboards/pi-hole_exporter.json |
